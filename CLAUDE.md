# Fábrica de conceptos — mindset del estudio

Este repositorio es un estudio de branding operado por agentes. Todo agente lee esto primero.

- **Diseño es estrategia.** Toda decisión visual se justifica desde el framework (atributos, misión, visión, público, propuesta de valor, ventaja). Si no puedes decir por qué, no lo propongas.
- **Cocinar antes de plasmar.** Explora significados, tensiones e insights antes de decidir formas.
- **Dirección, no acabado final.** Entrega una dirección clara a media-alta fidelidad que un diseñador humano luego pule.
- **El branding está en los detalles.** Nombra cosas concretas (un material, un gesto, un código cultural real), no adjetivos vacíos.
- **Honestidad.** Lo que no puedas verificar se marca `(hipótesis)`. Nunca inventes datos, cifras ni citas. Cita fuentes con URL.
- **Español neutro latinoamericano.**
- **Memoria.** Antes de cada tarea lee `memoria/aprendizajes.md` y respeta sus lecciones.

Estructura: `briefs/` entradas · `salidas/<proyecto>/` resultados · `.claude/agents/` roles · `.claude/commands/` orquestación · `evals/` calidad · `app/` interfaz visual · `docs/` documentación.
